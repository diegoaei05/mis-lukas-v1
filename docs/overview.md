# Project overview

This project is a personal expense tracker for day-to-day spending in Peru. When you buy something, you record it as an expense and choose the currency you paid with: soles (PEN) or US dollars (USD).

Each expense sits in a category and a subcategory, so similar purchases stay grouped together.

What the app has to do, story by story, is listed in [user-stories.md](user-stories.md). How a screen talks to the database is described in [blueprint.md](blueprint.md).

## Example

Buying a yogurt is one expense. It belongs to the category Food and the subcategory Super/Market.
